## 水杉阅读 v1.5.4

本次是**阅读页顶栏常驻改造**：章节名与页码一直显示在右上角，不用点屏幕唤出；顶栏不再挤在一起，正文始终从顶栏下方排版、不被遮挡。朗读、工具箱、法律文案、权限、隐私弹窗均未改。

### 解决的问题

v1.5.3 有三个反馈：① 顶栏四个元素挤在一起；② 右上角看不到当前章节和页数；③ 沉浸态把整个顶栏隐藏了，位置信息要点屏幕才出现。

### 修复内容

- **顶栏常驻**：从悬浮覆盖层（`position:absolute`）改为 flex 布局流内元素，沉浸态也保留。正文自动排在顶栏下方，绝不遮挡（实测正文标题从顶栏下方开始）。
- **右上角一直显示章节 + 页码**：完整格式「`01 · 第一章　林间的清晨 · 第1/4页`」，章节名只显示一次、用完整标题，翻页自动更新。
- **不再挤**：顶栏中间用弹性空白撑开，章节名与页码靠右紧凑排列；返回书架、目录两个按钮只在点屏幕唤出控制条时出现，沉浸态自动隐藏。
- Service Worker 缓存 `inkreader-v27 → v28`，`css/style.css` 已从复用列表摘出，确保老用户升级拿到新布局。
